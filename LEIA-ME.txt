  Autor / Personalização: Emerson Teles

  Compatibilidade:        Google Antigravity v2.35.1 / v2.35.2 (Windows x64)
  Idioma:                 Português do Brasil (pt-BR)

--------------------------------------------------------------------------------
  1. O QUE ESTE PACOTE FAZ
--------------------------------------------------------------------------------
  Traduz a interface completa do Google Antigravity para Português do Brasil,
  incluindo:
  • Tela inicial, barra lateral, menus nativos e bandeja do sistema (Tray)
  • Painel de chat, agentes, modelos, permissões, atalhos e configurações
  • Paleta de comandos (Ctrl+Shift+P / Ctrl+K / Ctrl+P / Ctrl+Shift+K)
  • Painéis laterais: Android Device Hub, Compose Preview e Visualizador
    Biomolecular (Mol*)
  • Mensagens de integração WSL (dist/wsl.js e dist/main.js)

  O pacote inclui Node.js portátil em runtime\ e funciona offline a partir de
  qualquer pasta.

--------------------------------------------------------------------------------
  2. COMO USAR
--------------------------------------------------------------------------------
  • INSTALAR OU ATUALIZAR A TRADUÇÃO:
    1. Feche o Antigravity (ou deixe o instalador fechar automaticamente).
    2. Dê dois cliques em "Instalar-Traducao.bat".
    3. Ao finalizar, pressione S para abrir o Antigravity ou N/Enter/Esc para sair.

  • VOLTAR PARA O ORIGINAL EM INGLÊS:
    1. Dê dois cliques em "Restaurar-Original.bat".
    2. O instalador restaura os arquivos originais de fábrica a partir do backup
       em "_backups\<versão>\" e limpa o cache de interface.

--------------------------------------------------------------------------------
  3. ARQUIVOS PRINCIPAIS DA PASTA
--------------------------------------------------------------------------------
  • Instalar-Traducao.bat         -> Atalho principal para aplicar a tradução.
  • Restaurar-Original.bat        -> Atalho para restaurar o Antigravity original.
  • aplicar-traducao.ps1          -> Script de instalação e limpeza de cache.
  • Restaurar-Original.ps1        -> Script de restauração a partir do backup.
  • patch-antigravity.cjs         -> Motor dinâmico de patch no app.asar e WSL.
  • web-bundle/                   -> Interface web traduzida (main.js e assets).
  • biomolecular-sidecar/         -> Traduções do Visualizador Biomolecular.
  • sync-biomolecular-sidecar.ps1 -> Sincronizador do sidecar biomolecular.
  • sync-android-sidecars.ps1     -> Sincronizador dos painéis Android.
  • CHANGELOG.md                  -> Histórico completo de versões e correções.
  • LEIA-ME.txt                   -> Este guia rápido.

--------------------------------------------------------------------------------
  4. SEGURANÇA E BACKUP
--------------------------------------------------------------------------------
  • Antes de modificar qualquer arquivo, o instalador salva uma cópia exata
    do "app.asar" original em:
      %LOCALAPPDATA%\Programs\antigravity\_backups\<versão>\app.asar
  • O backup original nunca é sobrescrito por arquivos traduzidos.
  • O comando "node tools\verify-clean-asar.cjs" valida que o pacote está limpo.
